Программа распознает лицо Стэйтема, рисует овал вокруг лица, накладывает очки на глаза, а также размывает лицо. 
В терминале загрузить библиотеки: pip install opencv-python opencv-python-headless numpy
Помимо библиотек указать правильный путь к двум изображениям, которые имеются в 5 и 6 строках кода. У меня этот путь:
img_path = 'C:\\Users\\User\\Desktop\\pythonproject\\stathamactor.png'
glasses_path = 'C:\\Users\\User\\Desktop\\pythonproject\\glasses.png'
